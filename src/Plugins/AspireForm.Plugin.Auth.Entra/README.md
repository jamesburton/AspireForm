# AspireForm.Plugin.Auth.Entra

Microsoft Entra External ID OIDC authentication Module provider for [AspireForm](https://github.com/jamesburton/AspireForm).
Scaffolds an `EntraAuthSetup.cs` helper and a managed AppHost-region comment using shared helpers from `AspireForm.Plugin.Auth.Common`.

## Block type

`auth-entra` (Module)

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `tenantId` | string | `"<tenant-id>"` | Entra tenant id. |
| `clientId` | string | `"<client-id>"` | App registration client id. |
| `audience` | string | _(clientId)_ | JWT audience (defaults to clientId). |

## File actions

| File | Ownership | Description |
|---|---|---|
| `<apphost>/EntraAuthSetup.cs` | Scaffold | Starter helper with `TenantId`, `ClientId`, and `Audience` constants. Edit freely — AspireForm will not overwrite it. |
| `<apphost>/AppHost.cs` | Managed region `auth-entra` | Registration comment generated by `AuthScaffold.RenderRegistrationComment`. |

## Example

```yaml
modules:
  entra-auth:
    type: auth-entra
    tenantId: my-tenant-id
    clientId: my-client-id
    audience: my-audience
```

## Dependencies

This plugin depends on `AspireForm.Plugin.Auth.Common` (shipped as a transitive runtime dependency — no separate install needed).

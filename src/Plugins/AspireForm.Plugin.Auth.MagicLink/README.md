# AspireForm.Plugin.Auth.MagicLink

Passwordless magic-link authentication Module provider for [AspireForm](https://github.com/jamesburton/AspireForm).
Scaffolds a `MagicLinkAuthSetup.cs` helper and a managed AppHost-region comment using shared helpers from `AspireForm.Plugin.Auth.Common`.

## Block type

`auth-magiclink` (Module)

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `fromAddress` | string | `"noreply@example.com"` | Email "From" address for outgoing magic-link emails. |
| `tokenLifetimeMinutes` | int | `15` | Magic-link token lifetime in minutes. |

## File actions

| File | Ownership | Description |
|---|---|---|
| `<apphost>/MagicLinkAuthSetup.cs` | Scaffold | Starter helper with `FromAddress` and `TokenLifetimeMinutes` constants. Edit freely — AspireForm will not overwrite it. |
| `<apphost>/AppHost.cs` | Managed region `auth-magiclink` | Registration comment generated by `AuthScaffold.RenderRegistrationComment`. |

## Example

```yaml
modules:
  magic-auth:
    type: auth-magiclink
    fromAddress: noreply@myapp.com
    tokenLifetimeMinutes: 30
```

## Dependencies

This plugin depends on `AspireForm.Plugin.Auth.Common` (shipped as a transitive runtime dependency — no separate install needed).

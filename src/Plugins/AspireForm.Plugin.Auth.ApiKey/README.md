# AspireForm.Plugin.Auth.ApiKey

API-key authentication Module provider for [AspireForm](https://github.com/jamesburton/AspireForm).
Scaffolds an `ApiKeyAuthSetup.cs` helper and a managed AppHost-region comment using shared helpers from `AspireForm.Plugin.Auth.Common`.

## Block type

`auth-apikey` (Module)

## Inputs

| Input | Type | Default | Description |
|---|---|---|---|
| `headerName` | string | `"X-API-Key"` | The HTTP header name carrying the API key. |
| `keysSource` | string | `"config"` | Source for valid keys: `"config"` (appsettings) or `"db"` (database). |

## File actions

| File | Ownership | Description |
|---|---|---|
| `<apphost>/ApiKeyAuthSetup.cs` | Scaffold | Starter helper with `AddApiKeyAuth` extension method. Edit freely — AspireForm will not overwrite it. |
| `<apphost>/AppHost.cs` | Managed region `auth-apikey` | Registration comment generated by `AuthScaffold.RenderRegistrationComment`. |

## Example

```yaml
modules:
  api-auth:
    type: auth-apikey
    headerName: X-My-Key
    keysSource: db
```

## Dependencies

This plugin depends on `AspireForm.Plugin.Auth.Common` (shipped as a transitive runtime dependency — no separate install needed).
